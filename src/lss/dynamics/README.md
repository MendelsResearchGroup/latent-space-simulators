# AE and propagator

- `autoencoder.py`: graph encoders and position decoders.
- `propagator.py`: latent dynamics models.
- `training.py`: AE and propagator fitting.
- `experiment.py`: datasets, splits, training orchestration, checkpoints and result tables.
- `evaluation.py`: physical p-ratio R² from AE reconstruction and autonomous rollouts.
- `analysis.py`: post-fit latent and response analysis.

Use `notebooks/dynamics/` for the visual workflows. Variant simulator modules remain available for recorded experiments. Read `docs/project_structure.md` and the results index before choosing a new experiment.
