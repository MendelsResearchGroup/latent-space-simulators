# Network engineering

Open [01 — Adam network engineering](01_adam_engineering.ipynb) for compact original-versus-optimized statistics and four-second trajectory GIFs: ten Reids and thirty mixed-temperature dePablo networks. Run all cells to refresh saved results; the notebook does not train models or run simulations.

Detailed sweep recipes, controls and provenance remain in [the engineering log](../latent_space/network_engineering_log.md) and [presentation provenance](../results/adam_showcase/README.md).

Open [02 — Engineer one network](02_engineer_one_network.ipynb) to run joint Adam on one original network, save the final design, verify compression, and create a four-second comparison GIF beside the notebook. The frozen AE and response-calibrated readout guide optimization; LAMMPS only verifies the saved final graphs. This known Reid example checks the workflow and does not constitute a new held-out study.
