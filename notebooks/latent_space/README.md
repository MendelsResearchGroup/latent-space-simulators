# Research logs

This directory retains historical log paths and experiment IDs for provenance. Active AE/propagator notebooks have moved to [dynamics](../dynamics/README.md); engineering notebooks are in [engineering](../engineering/README.md).

Start with the [results index](experiment_results_index.md). Engineering recipes, cohort metrics and limitations are in the [engineering log](network_engineering_log.md). Historical notebook paths inside dated entries describe the layout at the time of those runs.
