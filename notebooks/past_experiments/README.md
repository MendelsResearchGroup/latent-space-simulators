# Past experiments

These CV and full-space model notebooks are retained as historical experiments. Their model implementations live in `src/lss/past_experiments/`.

The old CV dataset `data_aux_opt_lowT_448sims_noang_bidirect.pt` is unavailable. Some notebooks use response fitting or response-based model selection. They are not current positions-only AE/propagator training recipes.

Use [dynamics](../dynamics/README.md) for current AE/propagator work and [engineering](../engineering/README.md) for Adam network design. Historical saved outputs do not establish reproducibility without the recorded inputs and checkpoints.
